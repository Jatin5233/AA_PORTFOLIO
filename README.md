# Aashita Malhotra — Digital Marketing World Tour

A premium single-page portfolio for Aashita Malhotra, designed as a sophisticated world tour through digital marketing, social media, SEO, content and measurable growth.

## Run locally

```bash
pnpm install
pnpm dev
```

The production build is available with `pnpm build`, and TypeScript validation runs with `pnpm check`.

## Replaceable image system

The experience uses intentionally polished visual placeholders rather than invented client photographs. Replaceable slot directories are available at `client/public/images/profile`, `arvind`, `helix`, `meetgoals`, `amity`, and `personal`. The current UI renders CSS-backed slots labeled with names such as `AASHITA_PORTRAIT`, `ARVIND_PROJECT_01`, and `PERSONAL_YOUTUBE_01`, so real imagery can be added later without changing the content architecture.

## Content guardrails

Role titles, dates, education, contact details and metrics are grounded in the supplied resume/source material. Social and professional profile links remain placeholders because no verified URLs were provided.
